# website-online-shop

Website Toko Online modern dan responsif built with Next.js & Tailwind CSS.

## Fitur
- Desain modern dengan animasi & efek visual Spline 3D
- Berbahasa Indonesia sepenuhnya
- Kategori produk lengkap (Fashion, Elektronik, Kesehatan & Kecantikan, Olahraga, Diskon)
- E-Payment integration layout

## Menjalankan secara Lokal

1. Install dependencies:
```bash
npm install
# atau
pnpm install
```

2. Jalankan server pengembangan:
```bash
npm run dev
# atau
pnpm dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser Anda untuk melihat hasilnya.
